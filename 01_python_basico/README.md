# 01. Python Básico

> **El objetivo:** Dominar la lógica de programación indispensable en Python sin morir en el intento de aprender ingeniería de software avanzada.

---

## 📖 Lecciones de este Módulo

1. [**Variables y Tipos de Datos**](./01_variables_y_tipos.ipynb) -> ¿Cómo guarda Python la información en la memoria? (Textos, números y estados).
2. [**Listas y Diccionarios**](./02_estructuras_datos.ipynb) -> Cómo agrupar múltiples datos (el anticipo mental a las tablas de Pandas).
3. [**Condicionales y Bucles**](./03_control_de_flujo.ipynb) -> Enseña a tu código a tomar decisiones automáticas y repetir tareas.
4. [**Funciones**](./04_funciones.ipynb) -> Crea tus propias herramientas reutilizables.

---

## 💡 ¿Por qué este enfoque?
En ciencia de datos no necesitas saber programar sistemas operativos; necesitas saber **cómo estructurar la información**. Al finalizar este módulo, sabrás leer y escribir la sintaxis básica para empezar a manipular tablas en los siguientes módulos.
