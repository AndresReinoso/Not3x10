# Ciencia de Datos Paso a Paso

Bienvenido a **Not3x10**, un proyecto diseñado para eliminar la complejidad innecesaria en el aprendizaje de la Ciencia de Datos con Python. Acá no encontrarás teoría abstracta ni explicaciones eternas.

---

## Los 6 Problemas que Combatimos

1. **Lenguaje Complejo** $\rightarrow$ Explicaciones directas.
2. **Mucha Información** $\rightarrow$ Síntesis extrema (ir directo al grano).
3. **Ejemplos Abstractos** $\rightarrow$ Casos basados en problemas reales.
4. **Pocos Ejemplos Prácticos** $\rightarrow$ Código ejecutable desde el día 1.
5. **Organización Deficiente** $\rightarrow$ Estructura modular y estandarizada.
6. **Conexión Real con el Aprendizaje** $\rightarrow$ Retos aplicados y proyectos.

---

## Ruta de Aprendizaje (Roadmap)

Sigue los módulos en orden secuencial para ir desde cero hasta la implementación de modelos:

| Módulo | Tema | Descripción Práctica |
| :--- | :--- | :--- |
| [**01_python_basico**](./01_python_basico) | **Fundamentos con Python** | Lógica computacional y estructuras de datos básicas. |
| [**02_limpieza_de_datos**](./02_limpieza_de_datos) | **Data Cleaning & Pandas** | Tratamiento de nulos, duplicados y datos atípicos. |
| [**03_enriquecimiento_de_datos**](./03_enriquecimiento_de_datos) | **Data Wrangling** | Uniones (`joins`), transformaciones y variables derivadas. |
| [**04_estadistica**](./04_estadistica) | **Estadística Intuitiva** | Análisis exploratorio (EDA), distribuciones e inferencia visual. |
| [**05_machine_learning**](./05_machine_learning) | **Modelos Predictivos** | Regresión, clasificación y evaluación con Scikit-Learn. |
| [**06_proyectos_integradores**](./06_proyectos_integradores) | **Casos Prácticos End-to-End** | Proyectos integradores aplicados a problemas del mundo real. |
